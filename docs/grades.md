# Grades

- **Aequitas Q**: Settings → **Grades** reads your current grade in each class from your school's grade system, so far only **Aequitas Q** (StudentConnection). Paste the *whole* address of your Q login page, including everything after the school's name (like `https://q.yourschool.org/Production/StudentPortal`; just `q.yourschool.org` isn't enough, and it's different for every district), your username and your password. Q signs you out after a while, so ClassDash signs in fresh each time, at most once an hour, and signs out again. On a Mac the password is kept in your Keychain, never in ClassDash's settings; on Windows it's in a file of its own that only your user account can read. If Q turns the password down, ClassDash stops trying until you change it, so the account doesn't get locked. If Q signs you in but then asks for a new password (an expired one), ClassDash signs out, stops the same way, and shows you what Q said with an **Open Q** button: set the new password on Q's site in your browser (ClassDash never changes it for you), then save it in Settings → Grades, and ClassDash checks again right away. Q gets its own status dot beside Classroom, Canvas and Edpuzzle.
- **Canvas grades** need no setup: when Canvas is set up, each course's current score and letter grade come along with every check.
- **Google Classroom grades** need none either: once an hour per class, ClassDash reads that class's "View your work" page and adds up the points you've been graded on. A class with nothing graded yet isn't listed.
- **One grade per class**: in Settings → **Classes** you can link a Q class to its Classroom or Canvas class (Q's are marked Q). A class with grades from more than one place goes by Q's, where your school really keeps them, then Canvas's, then Classroom's: that's the one the Grades list and the home API show. A link left without a name takes the name of its class with the most assignments.
- **The Grades list** sits on the main page, by period. **Hide** masks the grades (the class names stay) and remembers it.
- **Grade history and alerts**: ClassDash keeps each class's grade every time it changes, starting from the first time it reads it. The Grades list marks a change from the last week with ▲ or ▼ and by how much, and the Grades center draws each class's grade over time. Settings → **Grades** → **Grade alerts** sends a notification when a grade changes: on every change (the default), only when one goes down, or never. Notifications only show on a Mac for now; on Windows the marks and the history are how you see a change.
- **Grades center**: the **Grades center** button on the Grades list opens every assignment's score by class (points out of, percent, missing and late work, teacher comments), with an AI sidebar to ask about them, like "what do I need on the next test to get a B?". It uses the AI you picked in Settings → **AI**, or the one picked with the button under its question box (the same pick as the workspace's AI pane): a local one keeps your grades on your computer; with a cloud one, you tick a box first saying your grades and teacher comments go to that company. The chat is kept until you press **Clear chat**. A class linked across places shows once, under the grade it goes by, with the other places' assignments folded in underneath. The AI also sees each class's upcoming work from Classroom, Canvas and Edpuzzle, so you can ask what's coming up. For Canvas classes it also shows the teacher's categories (Tests, Homework…) with their weights, and ClassDash's own estimate of the grade from them; where a teacher hides the overall percent, the Grades list shows that estimate with a ~. For Q classes with a progress report (the printer button beside the grade on Q's site), ClassDash reads that PDF at each Q check: every assignment of the term instead of Q's last two weeks, each one's category, teacher comments, and dropped work. Q never shows how much each category counts, so the Grades center has a **Category weights** box per Q class: type them in from the syllabus and ClassDash works out your grade from them, and tells you whether that lands exactly on Q's grade (if it does, they're the teacher's weights). You can also paste the syllabus into the AI sidebar: it fills in the categories you haven't given a weight yet, using only numbers from what you pasted, and never changes one you've already entered.

The Grades center's AI chat uses the same AI settings as the rest of ClassDash: see [AI](ai.md).
